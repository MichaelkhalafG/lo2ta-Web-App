## Traps for the next reader

- Git Bash rewrites `/path` arguments into Windows paths: use `MSYS_NO_PATHCONV=1` for scripts that take URL paths.
- Headless Chrome will not go below a 500px viewport; phone checks use device-metrics emulation over CDP.
- Writing PHP or Windows paths through `node -e` or `sed` mangles backslashes: use the Write or Edit tool.
- Start Next without `-H`; the core API must be running for `pnpm build` in web. Before restarting `next start`,
  stop the old one by its port (3000): a second start fails silently while the old server serves a replaced build.
- React 19 resets a form after its server action: return the typed values on error and revalidate on success.
